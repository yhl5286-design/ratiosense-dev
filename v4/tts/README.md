# 캐릭터 음성 파일 넣기

브라우저 내장 음성(speechSynthesis)에는 한국어 **남성** 목소리가 없습니다.
윈도우/크롬북에 설치된 한국어 음성은 Heami·Google 한국의 두 가지이며 둘 다 여성입니다.
그래서 "젊은 남자 / 중년남자1 / 중년남자2"는 미리 만든 음성 파일로만 구현할 수 있습니다.

## 순서

1. `lines.csv`를 엽니다. 대사 27개가 캐릭터별로 정리되어 있습니다.
2. 네이버 클로바보이스(또는 다른 TTS)에서 캐릭터별 화자를 정해 각 대사를 합성합니다.
   - 뭉크 → 젊은 남성 화자
   - 먼셀 → 중년 남성 화자 (낮고 차분한 톤)
   - 시냐크 → 중년 남성 화자 (밝고 경쾌한 톤)
   - 안내(narrator) → 여성 화자
3. 받은 mp3를 `lines.csv`의 **파일명** 열과 똑같은 이름으로 이 폴더에 저장합니다.
4. `manifest.js`를 열어 주석 안의 목록을 밖으로 꺼내고 각 줄의 `//`를 지웁니다.

파일이 있는 대사는 mp3가 재생되고, 없는 대사는 자동으로 브라우저 음성으로 대체됩니다.
중간에 일부만 넣어도 동작합니다.
